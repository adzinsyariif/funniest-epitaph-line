A one-line tombstone epitaph of famous last words for the make.fun bounty
"Famous Last Words: The Funniest Epitaph" (at most 150 characters).

> Here lies Dave. His famous last words: 'Relax, I saw a tutorial once.'

## Run

```bash
python3 main.py
cat /output/entry.txt
```

The program writes the epitaph to `/output/entry.txt` as UTF-8 with no
trailing newline.
